## Paper Abstract
While diffusion models excel at image generation, their denoising trajectories pass through corrupted intermediate states far from the image manifold. We introduce Speed-Variation Distillation, a generative framework built around a variation-reducing degradation process that contracts diverse images toward a shared prototype while preserving recognizable intermediate states throughout the entire trajectory.
